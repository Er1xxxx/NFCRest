# Dastarhan HTML

Полный сайт меню за столом: меню, корзина, заказ официанту в Telegram, вызов официанта, оплата после еды, закрытие старого доступа и отзывы.

## Локальное демо

```bash
npm install
npm run demo
```

Локальное демо имитирует Telegram. Реальные сообщения и платежи не отправляются.

## Публикация

Нужен аккаунт Cloudflare:

```bash
npm install
npm run deploy
```

После публикации откройте `/admin`, задайте пароль, добавьте столы и настоящее меню, укажите Telegram ID официантов/кассиров/администратора, подключите два разных бота и выполните пробный заказ. Приём заказов включайте после проверки.

Токены `ORDERS_BOT_TOKEN` и `ADMIN_BOT_TOKEN` хранятся только в секретах сервера. Не вставляйте их в HTML, JavaScript, GitHub или сообщения.

Официант открывает стол и сообщает шестизначный код. Гость сканирует постоянную NFC/QR-ссылку, вводит код и отправляет заказ. Кассир проверяет полную оплату и подтверждает её в Telegram или админке. После закрытия старый доступ больше не принимает заказы. Отзыв доступен 7 дней; оценки 1–3 отправляются администратору.

Обычная ссылка Kaspi не сообщает сайту факт перевода автоматически: оплату проверяет кассир.

GitHub подходит для хранения исходного кода, а рабочее коммерческое размещение выполняется через Cloudflare Worker и D1. Перед запуском проверьте HTTPS, webhook, cron, резервные копии, меню, реквизиты оплаты и пробный заказ.
